# Public Health Surveillance & Analytics Platform -- dependencies
#
# Every dependency is pinned to an exact version, added only once the
# project genuinely needed it.
#
# The line below installs this repo's own package (src/surveillance_platform)
# in editable mode. Locally this is normally done with a separate
# `pip install -e .` step, but Streamlit Community Cloud only ever runs
# `pip install -r requirements.txt` -- without this line, the deployed
# app fails immediately with ModuleNotFoundError on the first internal
# import, since the src-layout package was never actually installed.
-e .

# pandas' own core dependency, and also used directly for forecasting
# math. Pinned exactly (not left to install transitively) after a
# real reproducibility gap was found: an unpinned numpy/scipy combo
# produced a materially different MASE score on a real backtest than
# the one already documented, even though the underlying finding
# (SARIMA loses to the baseline for that track) stayed the same.
numpy==2.4.4

# Interactive analytical visualization.
plotly==6.9.0

# SARIMA is the project's locked primary forecasting approach (see
# docs/adr/ADR-009-forecasting-strategy.md).

# statsmodels' numerical optimizer backbone -- the actual source of
# the reproducibility gap noted above, since it directly affects the
# model-fitting math.
