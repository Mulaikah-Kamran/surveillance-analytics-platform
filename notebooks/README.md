# Notebooks

Optional exploratory notebooks live here. Per the Freeze Document
(Section 26, Dependency Management): *"Notebooks are treated as
optional exploratory tools, not part of the production workflow —
consistent with the project being research software, not a
notebook-driven analysis."*

No notebooks exist yet at Milestone 1. Any exploratory notebooks added
in later milestones are supplementary to, and never a substitute for,
the tested `src/` modules.
